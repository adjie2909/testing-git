# Test Push Repository

Repositori ini digunakan untuk menguji alur kerja Git (commit & push) ke GitHub.

## 🚀 Fitur Uji Coba

- [x] Inisialisasi repositori Git
- [x] Tambah commit pertama
- [ ] Push ke branch `main`

## 🛠️ Langkah Menjalankan Push

Jalankan perintah berikut di terminal Anda:

```bash
# 1. Cek status repositori
git status

# 2. Tambahkan perubahan ke staging area
git add .

# 3. Buat commit
git commit -m "feat: initial test push"

# 4. Kirim perubahan ke GitHub
git push origin main
```
